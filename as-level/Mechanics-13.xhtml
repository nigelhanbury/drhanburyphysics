Rotational Equilibrium

For an object to be in rotational equilibrium, the sum of the clockwise moments about any stated point must be equal to the sum of the anticlockwise moments about the same point, i.e. for any system that is not rotating, the resultant moment about any point is zero.

The example below, represents a rod that is balanced. Initially, it is sometimes easier to lay out your working using headings as this will help you form an equation.

The Principle of Moments

For a system to be in equilibrium, ∑ anticlockwise moments about a point = ∑ clockwise moments about the same point.

It is common to use the sigma symbol, Σ to represent summation.
