Example Problem

For the following interaction verify whether the three conservation laws have been obeyed. Explain which force was responsible for the interaction.

A high energy interaction between a proton and a pion p + π  −  → n + π  + + π  − .

Solution

Conserved quantities

LHS

RHS

Charge (Q)/e

0

0 + (+1) + (−1) = 0

Lepton number (L)

0

0 + 0 + 0 = 0

Baryon number (B)

+1

(+1) + 0 + 0 = +1

Quark number

+3

(+3) + 0 + 0 = +3

The conservation laws have been obeyed as all 4 are the same before and after the interactions.

Strong force responsible:

Only hadrons present

No photons, leptons or flavour changes.
