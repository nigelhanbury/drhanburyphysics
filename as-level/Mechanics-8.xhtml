Vector Addition using Components

The vector addition of non-perpendicular vectors can be achieved by making use of components. Diagram A below, represents a vector addition. Here, the arrow to tail method has been used. Each vector has been resolved into its perpendicular components and shown in blue. By directly comparing diagrams A and B, it can be seen that the horizontal component of c is simply the sum of the individual horizontal components, eg, cH = aH + bH. Similarly for the vertical component, cV = aV + bV. Now, the magnitude and angle of c can be determined as before.
