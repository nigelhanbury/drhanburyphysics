Impedance of CR Network

Substituting V  R0 = I  0 R and V  C0 = I  0 X  C into V  0  2 = V  R0  2  + V  C0  2  gives V  0  2 = I  0  2 ( X  C  2   +  R  2 ) .

Rearranging, gives   V  0  __  I  0   = √ ______  X  C  2   +  R  2   . The ratio   V  0  __  I  0   is known as the impedance, Z of the CR network, and has units of the ohm.

This is analogous to the total resistance. Therefore, Z = √ ______  X  C  2   +  R  2   . This can also be written as Z = √ __________   (  1 _ 2πfC  )  2  +  R  2   .

We can express tanθ =   V  C0  ___  V  R0   as tanθ =   I  0 X  C  ___  I  0 R  =   X  C  __ R  .
