Oscilloscopes are devices that are used to display time varying voltages, such as that produced from AC circuits.

The diagram on the right, represents an oscilloscope with the main components labelled. The device acts like a voltmeter and displays a time varying voltage on the screen. In the example shown, two sinusoidal voltages are displayed.

The grid is used, very much like graph paper, to take voltage and time readings.

The Controls

Each time varying voltage that is displayed is referred to as a trace. An oscilloscope has one or more channels, where each channel is able to display a trace on the screen. For the example above, there are two channels, labelled CH1 and CH2.

The horizontal axis is the time axis. The scale of the time axis is adjusted using the Time/Div control (time base). The time base can range from s/div to µs/div. There is only one time base control so that the traces can be compared, such as measuring the phase difference.

The vertical axis is the voltage axis. The scale of the voltage axis is adjusted using the Volts/Div control (Y-gain). Notice, that there are two Y-gain controls. There is a Y-gain control for each channel, allowing the voltage scale for each trace to be adjusted.

The horizontal position of the trace is adjusted using the X-POS control. There is only one X-POS control as we need to shift both traces by the same amount, otherwise we would alter the phase difference between the two traces.

The vertical position of the trace is adjusted using the Y-POS control. Notice, that there are two Y-POS controls. There is a Y-POS control for each channel, allowing the vertical position of each trace to be adjusted.

The example on the right, represents a trace waveform that needs to be adjusted, in order to make the most accurate measurement of rms voltage. The Y-gain has been changed from 4V/Div to 2V/Div in order to double the number of squares that represents the peak voltage V0. This reduces the percentage uncertainty in V0, and hence, Vrms.
