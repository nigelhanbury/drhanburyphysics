The diagram below, represents a β - source emitting β - particles in all directions.

The activity of the source represents the number of decays per unit time, and hence, the number of β - particles emitted per unit time. However, as can be seen from the diagram, only a small percentage will be detected by the G-M Tube. Therefore, the count rate will be less than the activity of the source. If the percentage is known, then the activity can be calculated from the count rate.

The half life of the source can still be measured by plotting the count rate C, against time t, as the count rate is directly proportional to the activity. In other words, C ∝ A .
