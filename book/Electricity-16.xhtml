Uses of Superconductors

Superconductors are used in MRI scanners in hospitals and particle accelerators (e.g. at CERN). These machines need very strong magnetic fields, which can be produced using electromagnets. The higher the current through an electromagnet, the greater the magnetic field. However, if ordinary wire was used in the electromagnets, too much power would be dissipated, and so, the electromagnet would get very hot. Since power dissipated can be calculated using P = I2R, the resistance of the wire will be zero and there is no heating effect. The electromagnets are cooled using liquid helium at about 4.2K (≈ -269°C).
