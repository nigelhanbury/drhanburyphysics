Using Radioactivity to Measure Thickness

The absorption properties of beta and gamma radiation can be useful in the measurement of thickness. The example below, demonstrates how gamma radiation can be used to control the thickness of sheet steel.

As the sheet steel passes between the rollers, pressure is applied, in order to change the thickness of the steel. A gamma source is placed as shown, with the corresponding detector immediately above. The detector monitors the count rate as the steel passes through. If the sheet steel is slightly too thick, the detector will register a decrease in the count rate. The computer system will then reduce the pressure on the rollers.

It is important to note, that even though gamma radiation is not blocked by steel, variation in absorption will occur for differing thicknesses. It would not be appropriate to use a beta source, as only a few mm of Aluminium is needed to block it. It would be more appropriate to use beta radiation to measure the thickness of paper or card. Alpha would not be useful in the measurement of any material thickness.

The theory of radioactive decay is based on probability. Radioactive decay is a random and spontaneous process. These terms have very specific meanings. The term random, refers to the fact that we cannot predict which nuclei will decay, only the probability of a decay is known. The term spontaneous, refers to the fact that radioactive decay is not influenced by external factors, such as pressure, temperature etc.

Consider the diagram on the right, representing a quantity of N unstable nuclei. These nuclei could decay by emitting either α, β or γ radiation. After one second, we can see that ΔN nuclei have decayed. In this particular example, this would be 3. We define the activity A, as the number of decays per unit time. In this case, the activity is seen to be 3 decays per unit time or per sec. The unit of activity A, is s−1. In this particular example, A = 3s−1.

1 s−1 = 1 Becquerel or 1 Bq. This is the SI unit of activity.

For any one particular unstable nuclei, there is a probability that it will decay within one second. This is known as the decay constant λ. Therefore, λ is defined as the probability per unit time that a particular nuclei will decay.

If there are N unstable nuclei, then we can estimate the number of decays that will occur in one second (the activity). The formula below is used to determine the activity.

A = λN . If the number of nuclei doubles, then the activity doubles. Therefore, we can also write A ∝ N .

Definition of Decay Constant

It is defined as the probability per unit time that a particular nuclei will decay.
