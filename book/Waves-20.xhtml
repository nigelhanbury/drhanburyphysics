Example Problem

The diagram below, represents white light passing through a red and violet filter, which is then incident on a diffraction grating of 1000 lines m m  -1 . The two first order beams are shown. [The wavelengths of the red and violet light is 700nm and 400nm respectively.]

Without calculation, explain why the angular displacement of the 1st order red beam is greater than that of the 1st order violet beam.

Determine the angular displacement of both 1st order beams

Determine the maximum order for both wavelengths

Determine the number of maxima displayed on the screen for each wavelength

If the filter was removed, such that white light passes through the grating, determine the range of wavelengths that would produce second order maxima.

Describe with the aid of a sketch, what would be seen on the screen.

Solution

Using nλ = dsinθ , we can write sinθ ∝ λ for constant n and d. Therefore, as the wavelength, λ increases, the angular displacement, θ increases [Valid only for θ < 90° ].

Using d =  1 _ N  , we obtain d =  1 __  10  6   = 10  -6 m , or d = 1000nm. For the violet beam, we can use nλ = dsinθ . Therefore, 1 × 400 = 1000 × sinθ , which leads to θ = 23.6°.

Similarly, for the red beam, 1 × 700 = 1000 × sinθ , which leads to θ = 44.4°.

For the 400nm wavelength, we can use n  max =  d _ λ  , leading to n  max =  1000 _ 400  = 2.5 . Therefore, max order is 2.

Similarly, for the 700nm wavelength, n  max =  1000 _ 700  = 1.4 . Therefore, max order is 1.

For the 400nm wavelength, the number of maxima on the screen is give by 2 × 2 + 1 = 5. Similarly, for the 700nm wavelength, 2 × 1 + 1 = 3.

We can use n  max =  d _ λ  and set nmax = 2. We can write λ =  d __  n  max   , and so λ =  1000 __ 2  = 500nm . The range of wavelengths is then given by λ ≤ 500nm.

The sketch is drawn below. Each wavelength has a zero order maxima at the mid point, and so, the overlapping colours produce a white band. A continuous 1st order spectrum is produced either side of the central white maxima along with a partial 2nd order spectrum with λ ≤ 500nm. There is only a maximum order of 1 for λ > 500nm
