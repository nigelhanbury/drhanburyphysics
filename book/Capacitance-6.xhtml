As the capacitors are connected in series, the current at any instant must be the same at all points within the circuit as this is a series circuit.

Since the current delivering charge to both capacitors is the same, both capacitors must receive the exact same charge Q, during the charging process, and the emf source must have delivered that same charge.

Therefore, each capacitor connected in series must store the same charge, Q.

Since the total charge delivered by the emf source during the charging process is Q, it follows that the total charge stored must also be Q.

The two circuits below can be considered identically equal, where C, represents the combined capacitance.

From DC circuits, we can make use of the fact that V = V  1 + V  2 , and V =  Q _ C  , to determine the combined capacitance, C.

Since each capacitor stores the exact same charge, we can write:

 Q _ C  =  Q __  C  1   +  Q __  C  2   , where V =  Q _ C  , V  1 =  Q __  C  1   and V  2 =  Q __  C  2   .

This reduces to  1 _ C  =  1 __  C  1   +  1 __  C  2   .

Useful Ratio for Capacitors in Series

Since each capacitor in series stores the exact same charge, we can make use of Q = CV .

Recognising that Q = C  1 V  1 and Q = C  2 V  2 , we can write C  1 V  1 = C  2 V  2 .

Therefore,   C  1  __  C  2   =   V  2  __  V  1   .

Formulae for series capacitors:

 1 _ C  =  1 __  C  1   +  1 __  C  2  

  C  1  __  C  2   =   V  2  __  V  1  

V  1 = V ×   C  2  ______  ( C  1  +  C  2 )  

Potential Divider Formula for Capacitors in Series

We can re - express  1 _ C  =  1 __  C  1   +  1 __  C  2   as C =   C  1 C  2  _____  C  1  +  C  2   . Using V  1 =  Q __  C  1   and Q = VC , we can write:

V  1 =  VC ___  C  1   = (  V __  C  1   ) ×   C  1 C  2  ______  ( C  1  +  C  2 )   = V ×   C  2  ______  ( C  1  +  C  2 )   .

For n capacitors in series:

 1 _ C  =  1 __  C  1   +  1 __  C  2   + ... +  1 __  C  n
